## 📥 Installation Steps

### Step 1: Clone the Repository

**Important**: Clone the `expiremental` branch, which contains all the latest features and fixes.

```bash
# Clone the repository and checkout the experimental branch
git clone https://github.com/Yukidoki1126/LegalKonect.git
cd LegalKonect
git checkout expiremental

# Verify you're on the correct branch
git branch
# You should see: * expiremental
```

### Step 2: Backend Setup (Laravel)

```bash
# Navigate to backend directory
cd backend

# Install PHP dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Create storage directories and set permissions (Linux/Mac)
chmod -R 775 storage bootstrap/cache

# For Windows, ensure storage and bootstrap/cache folders exist
# They should be created automatically, but verify they exist
```

### Step 3: Frontend Setup (React)

```bash
# Navigate to frontend directory from project root
cd ../frontend

# Install Node.js dependencies
npm install

# Copy environment file
cp .env.example .env
# Note: If .env.example doesn't exist in frontend, create .env manually (see Environment Configuration section)
```

## ⚙️ Environment Configuration

### Backend Environment (.env)

Edit `backend/.env` with your configuration:

```env
# Application Settings
APP_NAME=LegalKonect
APP_ENV=local
APP_KEY=base64:XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX  # Generated by php artisan key:generate
APP_DEBUG=true
APP_URL=http://localhost:8000

# Database Configuration
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=legalkonect
DB_USERNAME=your_mysql_username
DB_PASSWORD=your_mysql_password

# CORS Settings
FRONTEND_URL=http://localhost:3000

# Session & Cache
SESSION_DRIVER=file
CACHE_DRIVER=file
QUEUE_CONNECTION=sync

# Mail Configuration (REQUIRED - for email notifications)
# Using Resend (recommended - see docs/RESEND_QUICK_START.md)
MAIL_MAILER=resend
RESEND_KEY=your_resend_api_key  # Get from resend.com
MAIL_FROM_ADDRESS="noreply@legalkonect.com"
MAIL_FROM_NAME="LegalKonect"

# Alternative: For testing only (emails saved to logs instead of sending)
# MAIL_MAILER=log

# Payment Gateway (Optional - required for payments)
# PayMongo Configuration
PAYMONGO_PUBLIC_KEY=your_paymongo_public_key
PAYMONGO_SECRET_KEY=your_paymongo_secret_key

# PayPal Configuration
PAYPAL_MODE=sandbox  # Use 'live' for production
PAYPAL_CLIENT_ID=your_paypal_client_id
PAYPAL_SECRET=your_paypal_secret

# Google Services (Optional - for calendar and maps)
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_REDIRECT_URI=http://localhost:8000/api/google/callback
GOOGLE_MAPS_API_KEY=your_google_maps_api_key

# File Storage
FILESYSTEM_DISK=local
```

### Frontend Environment (.env)

Create `frontend/.env` with:

```env
# Backend API URL
REACT_APP_API_URL=http://localhost:8000/api

# Google Maps API Key (Optional - for location features)
REACT_APP_GOOGLE_MAPS_API_KEY=your_google_maps_api_key

# Payment Gateway Keys (Optional - for client-side payment integration)
REACT_APP_PAYMONGO_PUBLIC_KEY=your_paymongo_public_key
REACT_APP_PAYPAL_CLIENT_ID=your_paypal_client_id
```

## 👥 Sharing Setup with Team Members

### ⚠️ IMPORTANT: .env File Security

The `.env` files contain sensitive information (API keys, database passwords, secrets) and should **NEVER** be pushed to GitHub. When sharing your setup with team members, follow these steps:

### For the Project Owner:

**1. Files Already in GitHub** (Team members will get these automatically):
- All source code
- `backend/.env.example` (template without real keys)
- `frontend/.env.example` (if it exists)
- All documentation

**2. Files to Send SECURELY** (NOT via GitHub):
- `backend/.env` - Contains all sensitive keys and credentials

**How to Share .env Securely:**
- ✅ **Encrypted Messaging**: WhatsApp, Signal, Telegram (password-protected)
- ✅ **Password-Protected ZIP**: Email with strong password, share password separately
- ✅ **Secure File Sharing**: Services like Bitwarden Send, Firefox Send alternatives
- ✅ **In Person**: USB drive or direct transfer
- ❌ **NEVER**: GitHub, public email, Slack/Discord, unencrypted services

### For Team Members:

**Step 1: Clone the Repository**
```bash
git clone https://github.com/Yukidoki1126/LegalKonect.git
cd LegalKonect
git checkout expiremental
```

**Step 2: Get .env File from Project Owner**
- Request the `backend/.env` file through a secure channel
- Save it to `backend/.env` (NOT committed to Git)

**Step 3: Follow Installation Steps**
- Continue with [Backend Setup](#step-2-backend-setup-laravel) below
- Use the `.env` file you received instead of creating from `.env.example`

**Step 4: Configure Local Database**
- You may need to update database credentials in `.env` to match your local MySQL setup:
  ```env
  DB_DATABASE=legalkonect
  DB_USERNAME=your_local_mysql_username
  DB_PASSWORD=your_local_mysql_password
  ```

### What's Included in .env:
The backend `.env` file contains:
- ✅ Database credentials (host, username, password, database name)
- ✅ Application key (APP_KEY)
- ✅ Google OAuth credentials (CLIENT_ID, CLIENT_SECRET)
- ✅ Paymongo API keys
- ✅ Resend email API key
- ✅ JWT secrets
- ✅ All other API keys and sensitive configuration

### Security Best Practices:
1. **Never commit .env files** to version control
2. **Rotate keys** if accidentally exposed
3. **Use different keys** for development and production
4. **Share via encrypted channels** only
5. **Delete from messages** after team member saves it
6. **Use environment-specific configs** for each developer

## 🗄️ Database Setup

### Step 1: Create Database

```bash
# Login to MySQL
mysql -u root -p

# Create database
CREATE DATABASE legalkonect CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# Create user (optional but recommended)
CREATE USER 'legalkonect_user'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON legalkonect.* TO 'legalkonect_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### Step 2: Run Migrations

```bash
# Navigate to backend directory
cd backend

# Run database migrations
php artisan migrate

# Seed the database with initial data
php artisan db:seed

# Optional: Seed with sample data for testing
php artisan db:seed --class=FaqSeeder
php artisan db:seed --class=SuperAdminSeeder
```

### Step 3: Create Storage Directories

```bash
# Still in backend directory
php artisan storage:link

# Create required directories
mkdir -p storage/app/private/verification_documents
mkdir -p storage/app/private/case_documents
mkdir -p storage/app/public/lawyer_profiles
```

## 🔧 Troubleshooting

### Common Issues and Solutions

#### Issue 1: "Access denied for user" (MySQL Error)
**Solution**:
- Verify MySQL credentials in `backend/.env`
- Ensure MySQL server is running: `mysql -u root -p`
- Check database exists: `SHOW DATABASES;`

#### Issue 2: "Class not found" errors
**Solution**:
```bash
cd backend
composer dump-autoload
php artisan config:clear
php artisan cache:clear
```

#### Issue 3: "CORS policy" errors in browser
**Solution**:
- Verify `FRONTEND_URL` in `backend/.env` is `http://localhost:3000`
- Clear browser cache
- Check `backend/bootstrap/app.php` has CORS middleware configured

#### Issue 4: Frontend won't start - "Port already in use"
**Solution**:
```bash
# Windows (Port 5173 for Vite or 3000 for CRA)
netstat -ano | findstr :5173
taskkill /PID <PID> /F

# Mac/Linux
lsof -ti:5173 | xargs kill -9

# Or use npm package to kill port
npx kill-port 5173

# Or use a different port
PORT=3001 npm run dev
```

#### Issue 5: "Storage directory not writable"
**Solution**:
```bash
# Linux/Mac
cd backend
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

# Windows - Run as Administrator
icacls storage /grant Users:F /t
```

#### Issue 6: npm install fails
**Solution**:
```bash
# Clear npm cache
npm cache clean --force

# Delete node_modules and package-lock.json
rm -rf node_modules package-lock.json

# Reinstall
npm install
```

#### Issue 7: Database migration errors
**Solution**:
```bash
# Reset database (WARNING: This deletes all data)
php artisan migrate:fresh --seed

# Or rollback and re-run
php artisan migrate:rollback
php artisan migrate
```

## 🔌 Optional Features Setup

### Google Calendar Integration

1. **Create Google Cloud Project**:
   - Go to [Google Cloud Console](https://console.cloud.google.com/)
   - Create a new project
   - Enable Google Calendar API

2. **Create OAuth 2.0 Credentials**:
   - Go to Credentials → Create Credentials → OAuth client ID
   - Application type: Web application
   - Authorized redirect URIs: `http://localhost:8000/api/google/callback`
   - Copy Client ID and Client Secret to `backend/.env`

3. **Documentation**: See [docs/GOOGLE_CALENDAR_SETUP.md](./GOOGLE_CALENDAR_SETUP.md) for detailed instructions

### Google Maps Integration

1. **Get API Key**:
   - Go to [Google Cloud Console](https://console.cloud.google.com/)
   - Enable Maps JavaScript API and Places API
   - Create API key
   - Add key to both `backend/.env` and `frontend/.env`

2. **Documentation**: See [docs/GOOGLE_MAPS_SETUP.md](./GOOGLE_MAPS_SETUP.md) for detailed instructions

### Payment Gateway Setup

#### PayMongo (Philippines)
1. Sign up at [PayMongo](https://www.paymongo.com/)
2. Get API keys from dashboard
3. Add to `backend/.env` and `frontend/.env`

#### PayPal
1. Sign up at [PayPal Developer](https://developer.paypal.com/)
2. Create sandbox account for testing
3. Get Client ID and Secret
4. Add to `backend/.env` and `frontend/.env`

### Email Configuration

For development, use [Mailtrap](https://mailtrap.io/):
1. Create free account
2. Get SMTP credentials
3. Add to `backend/.env`

For production, use services like:
- SendGrid
- AWS SES
- Mailgun
